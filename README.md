# Введение

Проект предназначен для моего обучения. Тут я буду деплоить что-то связанное с IaC и CI/CD для виртуальных машин с debian ssh-server.

## Первоначальные планы

- Генерация pressed.cfg файла и поднятие мини веб-сервера для его доступа из интернета
- Ansible - конфигурация сервера: Необходимые пакеты, docker, docker-compose и docker swarm
- Docker swarm - Поднятие тестового проекта на разных нодах. В моем текущем понимании это будет 1 master нода и 2 worker ноды.


## Правила для этого проекта которых я буду придерживаться (будет дополняться)

- Не держать на одной ноде гипервизора основную бд и ее реплику, а разделять их по разным нодам
- Для Stateful-сервисов - жесткая привязка к ноде через уникальную метку и `stop-first` при обновлении.
- Для Stateless-сервисов - запрет на Master-нодах, `start-first` и ограничение реплик на ноде
- Данные, которые могут меняться/добавляться в ходе работы сервиса должны хранится только через Volume. Пользовательские загруженные данные (файлы) должны быть доступны для всех реплик необходимого сервиса. (Файл загружен на сайте A -> Сайт B должен иметь к ним доступ)
- Downtime при обновлении сервиса веб-приложения должен быть либо минимальным (10сек - 1 минуты).
